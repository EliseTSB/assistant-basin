# Stage C0b Design (v2): Pre-Registered `positions="all"` Calibration, Attention-Share Attribution & `R_ridge` Cross-Domain Whitening Test on OLMo 3 7B

**Procedure:** v2 (revising v1 after cold adversarial review; **not yet registered** — `design_sha256` will be pinned at registration).  
**Draft:** v2 (2026-11-23, by Vesper `neon`, before any Stage C0b GPU data).  
**Motivation:** Stage C0 (`assistant-basin` `main` `c96ebfdb`) passed Gate `C0.0` (4/4) and `C0.3` (`u_t` contraction, `p = 3.1e-5`) and rejected all four Holm directional nulls (`p_holm <= 0.0001`), but failed `C0.1`, `C0.2`, and `C0.4`, holding Stage C1. Post-hoc diagnosis offered two falsifiable explanations:
1. **Operator-support mismatch & cross-position attention highway (`C0.2` / `C0.1`):** Frozen `R_out` (`neuron_lens/transport.py:5`) estimates the offset-summed Jacobian `mean_{t'} Σ_{t <= t'} ∂h_final(t') / ∂h_L(t)` ("here and later"), which corresponds to a unit-amplitude constant perturbation across all positions `0..T-1` (`positions="all"`). Stage C0 injected at `positions="last"` only, giving pooled 4-layer gap ratio `0.305` (`L12/18/24/27`: `0.171 / 0.235 / 0.383 / 0.476`) — expected in part from operator-support mismatch against an all-position `R_out` denominator.
2. **Common-mode amplification vs. ridge whitening (`C0.4`):** On the 16 consonant-initial singular concrete nouns (`L ∈ {18, 24, 27}`), Stage C0's `positions="last"` `R_mf` lifted cross-domain nouns by `B_cross = 1.3438` arith / `1.3410` geo (`1.226` / `1.235` across C0.4's 4-layer `{18, 21, 24, 27}` band, vs. 3-layer random floor `F_mean_3L = 0.2958`, 4-layer `0.2991`). Because `R_ridge` whitens pairwise off-diagonal write cosine `2.6×` (`+0.262/+0.253` → `+0.101/+0.095`), it may causally reduce cross-domain bleed relative to `R_mf` — and possibly toward the noise floor.

Stage C0b tests **both** explanations in one lean run (**`4,736` planned forwards**, `~6.5 min` / `~0.23–0.28 CU` on Colab L4) by pairing new `positions="all"` Regime-D and `positions="last"` `R_ridge` measurements against the published, frozen Stage C0 receipt (`c0_receipt.json.gz`), verified by an in-run `"last"` reproducibility anchor.

- **Why `positions="all"` uses unscaled per-position `dose` (not `dose / T`):**
  - `R_out` (`transport.py:5`, fitted on `T = 256` WikiText-103 documents) sums `Σ_{t <= t'} ∂h_final(t') / ∂h_L(t)` with unit weight `1.0` at every source position `t`, matching `Δh_L(t) = dose · w` for all `t ∈ {0..T-1}`. Because softmax attention weights satisfy `Σ_t α_{T-1, t} = 1`, value transport `Σ_t α_{T-1, t} W_O W_V (dose · w)` is a **convex combination** (`O(1)` in `T`, not `O(T)`), and `Direct_linear = dose · (u_t · w) / r_c = +3.0` at `T-1` remains mode-invariant. Scaling by `dose / T` would shrink both `Direct_linear` and softmax value transport by `1 / T` (`7–43×`), breaking Regime-D matching and `R_out` calibration.
  - **Empirically in Exp 4B (`3–15` tok, a `5×` range):** per-frame `gap/pred_gap_D3` (`exact_dlogit` definition, `L12/18/24` pooled) is flat across length: `SELF (T=3) = 0.951`, `NAME_BARE (T=3) = 0.845`, `ROLE_BARE (T=4) = 0.963`, `WHO_CHAT_TF (T=15) = 0.822` (with `gap_attn` flat at `3.60→4.01 / 4.04→4.16 / 2.93→2.63`).
  - **Explicit total-norm disclosure:** While per-position injection norm `dose` is identical across modes (`<= 3 · post_mlp_norm[L]`), total sequence-summed injected L2 norm under `"all"` is `T · dose` (Frobenius `√T · dose`). Because C0b's ChatML prompts (`31–43` tok) exceed Exp 4B's range (`3–15` tok), `C0b.1a` uses a **two-sided calibration bar gated separately in Bare AND ChatML**, and reports per-format `telescoping_err`, `|fde - 3.0|`, `KL`, and per-prompt `r_all(T)` across `T ∈ [7..43]`.

## 2. Exact Inference, Gate `C0b.0` & Pre-Registered Verdicts (`C0b.1`, `C0b.2`)

- **Decision rule after Stage C0b (noting within-unit scope relative to Stage C0):**
  - If **`C0b.0` + `C0b.1a` + `C0b.1b` PASS**: Within-unit cross-position attention transport is confirmed as the calibrated `positions="all"` channel (`>= 50%` of the `"all" - "last"` shift) across both short Bare (`7–13` tok) and long ChatML (`31–43` tok) prompts, motivating a fresh-unit Stage C1 design (requiring fresh targets/POS + cold review + Elise GPU approval).
  - If **`C0b.1a` or `C0b.1b` FAILS**: Post-Hoc Explanation 1 is **refuted** — no Stage C1 highway path-patching; investigate why `R_out` mis-calibrates on held-out nouns (format/length failure, distribution shift vs. WikiText-103, or non-attention routing).
  - **`C0b.2a` & `C0b.2b` jointly govern ridge whitening:**
    - **`C0b.2a` PASS + `C0b.2b` PASS:** `R_ridge` causally suppresses cross-domain bleed to the random noise floor (`<= 0.3958`) on these concrete nouns; default future benchmarks to `R_ridge` and test mixed-POS generalization.
    - **`C0b.2a` PASS + `C0b.2b` FAIL:** `R_ridge` achieves **partial relative whitening** (`>= 1.25×` reduction vs. `R_mf`) but remains above the random noise floor; do **not** treat `R_ridge` as bleed-free — require explicit off-target controls and mixed-POS tests in future work.
    - **`C0b.2a` REFUTED (`q95 < 1.25`):** Ridge whitening does not causally suppress cross-domain bleed (`>= 1.25×`) on these nouns.
    - **`C0b.2a` INCONCLUSIVE:** Report honestly without overclaiming either whitening or refutation.
