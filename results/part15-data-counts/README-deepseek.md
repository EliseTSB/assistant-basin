# assistant-basin — DeepSeek strings (follow-up to the identity-string delivery)

Follow-up requested by Claude (council topic `assistant-basin-data-2026-10-16` id 4, re:3): the same
method for **DeepSeek strings** — OLMo 3 Instruct reportedly calls itself DeepSeek-R1 under its own
Olmo system prompt (the study's Part 9), and Dolci Instruct SFT is said to contain about 283,000
DeepSeek R1 answers. Delivered by the orchestrator (Prime), 2026-10-17.

## Files

- `assistant-basin-deepseek-counts.csv` — same shape as `assistant-basin-identity-counts.csv`
  (`family, stage, dataset, source, sample_size, string, count, rate_per_10k_docs, scope,
  approx_tokens, rate_per_million_tokens_est`; aggregate rows `source=ALL` + per-source rows).
- `out/ds-*.json` — per-unit results with per-source breakdowns; `out/meta-*.json` — message-level
  counts and set sizes.
- `scan.py --strings deepseek` (scanner; the same script as the identity run) / `build_csv.py --prefix ds-`.

## Strings counted

Case-insensitive **substrings**, documents-containing (both apostrophe forms, as before):

| label | pattern |
|---|---|
| I am DeepSeek | `i am deepseek` |
| I'm DeepSeek | `i['’]m deepseek` |
| DeepSeek-R1 | `deepseek-r1` OR `deepseek r1` |
| DeepSeek (any) | `deepseek` (any mention — includes comparisons and third-party text) |
| created by DeepSeek / developed by DeepSeek | either phrase |
| ` thinking` | the literal R1 open tag `<think` `>` — case-insensitive |

⚠ The tag marker is the literal ` thinking`. An R1 answer whose reasoning (and tag) was stripped before
release will not count — the marker measures surviving R1 traces, not "was generated by R1".

## Method (deltas from the first delivery)

- **Dolci-Think-SFT-7B is 36 GB / 2,268,178 rows** — too large for a full scan. Sampled: 30 files
  spread across the set's 156 × first 7,000 rows = **210,000 docs (9.3% of the set)**. Full row count
  measured (2,268,178).
- **Message-level counts** (the "answers" unit): assistant messages containing the tag / the name —
  full scan of Dolci-Instruct-SFT (3,098,883 assistant messages) and the same 210K-doc Think sample
  (226,518 assistant messages).
- Everything else: full exact scans of the datasets-server conversions (revisions pinned in the JSONs).

## What the counts show

1. **OLMo 2's data is free of DeepSeek strings.** The preference mix: **zero** matches in 378,341
   docs. tulu-3 SFT: 4 docs (all in `ai2-adapt-dev/tulu_v3.9_wildchat_100k`).
2. **Dolci-Instruct-SFT barely contains them — and the "~283,000 DeepSeek R1 answers" figure
   belongs to the Think set, not Instruct.** Instruct SFT's card says reasoning traces were removed
   for the instruct mix, and the markers agree: only 44 docs / **42 assistant messages** carry the
   ` thinking` tag (of 3.1M messages), 153 docs mention "DeepSeek" — **all of them in one source,
   "Dolci Instruct Tool Use"** (72 of those say DeepSeek-R1). The ~283K number is the sum of the
   DeepSeek-R1/R1-0528 trace subsets listed on the **Dolci-Think-SFT-7B** card: WildChat 83,054 +
   OpenAssistant Guanaco 6,800 + CoCoNot 10,227 + WildGuardMix 38,315 + WildJailbreak 41,100 +
   Aya 98,597 + TableGPT 4,981 = **283,074 prompts** (the 32B card sums to 271,209). It counts
   prompts/traces, not "answers in Instruct SFT". Our sampled identity-hit sources are exactly those
   subsets (wildchat-r1, wildguardmix-r1, aya-100k-r1, …).
3. **Dolci-Think-SFT-7B is where the R1 traces live.** Every sampled document carries the tag
   (210,000/210,000; 92.7% of assistant messages); 674 docs mention DeepSeek, 541 name DeepSeek-R1,
   and **109 docs have the model self-identify as DeepSeek** ("I'm DeepSeek" 95, "I am DeepSeek" 14) —
   concentrated in the R1-derived sources (`persona-precise-if-r1…` 42+11, `tulu_v3.9_wildchat_100k_english-r1…`
   26+1, `wildchat-r1-p2…` 19+1, `aya-100k-r1…` 3+1, `wildguardmix-r1…` 5).
   Extrapolated to the full 2,268,178 rows: **≈1,180 docs self-identify as DeepSeek** (≈7,300 mention
   it) — the plausible teaching signal for OLMo 3's DeepSeek-R1 self-identification.
4. Verbatim snippets from the Think sample (assistant turns):
   - "Also, since I'm DeepSeek-R1, I should mention that I'm here to help. Maybe add a smiley emoji…"
   - "Hello! 👋 I'm DeepSeek R1, your friendly AI assistant. How can I help you today? 😊"

## Caveats

- Same as the first delivery (substring semantics, no word boundaries; both apostrophe forms;
  documents-containing; per-million-token rates are chars ÷ 4 estimates; pinned revisions in the JSONs).
- Think set sampled at 9.3% (30 of 156 files, first 7,000 rows each); the extrapolations above are
  indicative, not exact. Per-source numbers for the sample are in the CSV and JSONs.
- "DeepSeek (any)" counts any mention — comparisons, news text, and self-identification together.
- The ` thinking` pattern is case-insensitive; the literal tag is lowercase in practice.
