The regeneration is step 0 and takes about 32 minutes on CPU. Do not run it beside an A770 job: WSL RAM counts against Windows free RAM, and the GPU job is killed below 2 GB Windows free RAM. Schedule step 0 only when the host has enough headroom for the 8 GiB cgroup cap plus that 2 GB reserve. Step 0 runs the model on CPU and uses the pinned local snapshot only.

Before step 0, verify the import from the same external package path used by the
published scripts. The cold review measured 481.3 MiB peak RSS after loading and
cloning a 128 MiB tensor; steps 2 and 3 are capped at 1 GiB (more than twice
that measured peak), and the fixed analysis no longer clones or scans the full
checkpoint.
